Methodology

Benchmarked 6 ML models on 37,000+ OBD-II vehicle telemetry records collected across multiple driving conditions and seasons. Implemented feature engineering with 18+ derived features. Used stratified cross-validation and grid search hyperparameter optimization.

Key Findings

CatBoost achieved best performance:

  • R² = 0.94 (94% variance explained)
  • MAPE < 10% (Mean Absolute Percentage Error)
  • MAE = 2.1 kWh (Mean Absolute Error)
  • Inference latency: 4.2ms
  • Outperformed XGBoost (R²=0.91) by 3%
